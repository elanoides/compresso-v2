# CRT Parametric Font Studio

Параметрический редактор модульных All-Caps шрифтов, работающий полностью в браузере.
Ни бэкенда, ни серверных вычислений: рендеринг превью, векторизация контуров, сборка
OpenType-бинарника и упаковка ZIP-архива происходят на клиенте.

**Стек:** React 19 · TypeScript · Vite · Tailwind CSS 4 · lucide-react · opentype.js · JSZip · file-saver

---

## Быстрый старт

```bash
npm install
npm run dev
```

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Дев-сервер Vite на `http://localhost:5173/` |
| `npm run build` | Проверка типов (`tsc --noEmit`) + продакшн-сборка в `dist/` |
| `npm run preview` | Локальный просмотр собранного `dist/` |
| `npm run typecheck` | Только проверка типов |

## Деплой

Пуш в `main` запускает `.github/workflows/deploy.yml`, который собирает проект и
публикует `dist/` на GitHub Pages. В настройках репозитория *Settings → Pages*
источник должен быть выставлен в **GitHub Actions**.

Сборка использует `base: '/compresso-parametric-studio-v2/'` — при переименовании
репозитория нужно обновить `REPO_BASE` в `vite.config.ts`.

## Шрифтовой движок

### Вертикальная сетка — 28 строк

| Строки | Зона |
| --- | --- |
| `0..3` | Верхние акценты (диакритика «Ё», «Й») |
| `4..23` | Тело прописного знака, Cap-Height = 20 строк |
| `23` | Baseline — по ней строго выравниваются все знаки строки |
| `24..27` | Нижние выносные элементы (хвостики «Ц», «Щ», ножки «Д») |

Ширина сетки: 5 колонок у стандартных знаков, 6–7 у широких («Ж», «М», «Ш», «Щ», «Ю», «W»).

### Типы модулей

Каждая заполненная клетка матрицы штампуется модулем одного из трёх типов:

- **Овал** — `rx`, `ry`, толщина обводки, прозрачность заливки.
- **Кастомный SVG** — загруженная разметка парсится в абсолютные кубические
  Безье (включая перевод дуг `A` в кубики и раскрытие `transform`), затем
  нормализуется в единичный бокс.
- **Символы шрифта** — контуры берутся из локальных SB Sans / SB Serif в
  `public/fonts/`. Масштабирование строго пропорциональное (uniform scale) по
  кеглю ячейки, без зеркалирования и нелинейного сжатия.

Вращение модуля (`-90°..+90°`) применяется вокруг локального центра каждого
модуля и учитывается при расчёте `viewBox`, поэтому графика не обрезается ни
при 45°, ни при наклоне.

### Деформации

- **Slant / Skew** относительно baseline: `x' = x + (y_baseline - y) · tan(θ)`.
- **Glitch / Jitter X** — детерминированный сдвиг отдельных модулей.
- **Scanline Shift** — детерминированный сдвиг целых строк.

Случайность детерминирована: `src/engine/hash.ts` содержит синхронный
UTF-8-совместимый SHA-256, поэтому один и тот же `seed` даёт одинаковый результат
в превью, в экспортированном SVG и внутри собранного шрифта.

## Экспорт

| Формат | Как собирается |
| --- | --- |
| **SVG** | Строка разметки из `engine/geometry.ts` — та же, что рисует превью |
| **OTF** | `engine/opentypeExporter.ts` запекает модули в контуры Безье через `opentype.js` |
| **ZIP** | `engine/zipExporter.ts` — папка на каждое начертание: SVG глифов, спесимен, `params.json`, готовый шрифт |

Кернинг сохраняется в шрифт двумя таблицами: современной `GPOS` (фича `kern`) и
легаси `kern` формата 0 — `opentype.js` их не пишет, поэтому
`engine/sfnt.ts` собирает бинарные таблицы и инжектит их в готовый sfnt.

`opentype.js` формирует CFF-контуры, то есть на выходе технически `.otf`, а не
`.ttf` — файлы устанавливаются и работают одинаково.

## Производительность

- `opentype.js` и `jszip` загружаются динамическими импортами и вынесены в чанк
  `font-tools`, поэтому не попадают в начальный бандл.
- Превью считается через `useDeferredValue`: перетаскивание слайдеров не
  блокирует ввод.
- Матрицы глифов после масштабирования плотности мемоизируются, контуры шрифтов
  кешируются по паре «начертание + символ».

## Структура

```
src/
├── data/
│   ├── glyphsData.ts        # матрицы координат символов + константы сетки
│   ├── moduleFonts.ts       # сгенерированный каталог файлов из public/fonts/
│   ├── moduleFontCatalog.ts # лукапы по каталогу без зависимости от opentype.js
│   ├── charPool.ts          # пул символов для модуля-шрифта
│   └── presets.ts           # базовый Regular и встроенные начертания
├── types/fontTypes.ts       # StyleParams, Preset, RenderContext и прочие типы
├── engine/
│   ├── glyphs.ts            # доступ к матрицам, масштабирование плотности
│   ├── geometry.ts          # раскладка, деформации, модули, renderTextSvg
│   ├── svgPath.ts           # парсинг и трансформация путей, bbox
│   ├── moduleStamp.ts       # разбор кастомного SVG в штамп
│   ├── fontPaths.ts         # ленивая загрузка контуров через opentype.js
│   ├── hash.ts              # SHA-256 для детерминированного рандома
│   ├── opentypeExporter.ts  # сборка OTF
│   ├── sfnt.ts              # бинарные GPOS / kern и инжект в sfnt
│   ├── zipExporter.ts       # CRT_Font_Family_Pack.zip
│   └── download.ts          # сохранение файлов
├── hooks/
│   ├── useStudio.ts         # состояние студии, пресеты, localStorage
│   └── usePresetContext.ts  # контуры для карточек галереи
├── components/
│   ├── Layout/              # Header, Sidebar, Tabs, Accordion
│   ├── Tabs/                # WordTester, GlyphInspector, PresetsGallery
│   └── controls/            # Slider, Inputs, Button
└── App.tsx
```

Библиотека начертаний хранится в `localStorage` и переносится между машинами
через кнопки экспорта и импорта JSON на вкладке «Начертания».
